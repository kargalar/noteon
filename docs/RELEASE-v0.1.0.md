## Noteon v0.1.0

The first public release of Noteon for Windows.

- Local-first notes workspace built with Rust and SQLite.
- Nested pages, searchable icons, covers, custom page properties, favorites, and trash.
- Block editor with drag-and-drop ordering, resizable columns, and image/video blocks.
- Table, gallery, and board database views with custom properties and sorting.
- Tabs and resizable dock panels for working across pages.
- Full-text search, Markdown import/export, automatic saves, and SQLite backups.
- Light/dark themes with adjustable colors and font size.

Download `Noteon-0.1.0-windows-x64.zip`, extract it, and start `Noteon.exe`. Video playback requires `ffmpeg` and `ffplay` on `PATH`.
