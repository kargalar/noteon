Quick guide

Ctrl + NNew page
Ctrl + FFind on page
Ctrl + KSearch workspace
Ctrl + SSave now or retry a failed save
Ctrl + BToggle or pin sidebar
Ctrl + JToggle Assistant panel
Alt + ← / →Previous or next page
EnterSplit at cursor and add a block
Shift + EnterNew line in the same block
Right-click a blockChange type, move, or delete

In an empty block, type /h1, /h2, /h3, /todo, /bullet, /number, /quote, /callout, /code, or /divider, then press Enter.

You can also start a block with #, -, [], or > followed by a space. Enter inserts a line break in code blocks.
